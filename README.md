# 데이터 분석 프로젝트 모음

데이터사이언스 전공 과정에서 진행한 분석·모델링 프로젝트를 정리했습니다.
정형 데이터 분류, 이미지 딥러닝, 챗봇 구현, 서비스 기획, 공공데이터 분석까지 다양한 형태의 데이터를 다뤘습니다.

## 프로젝트

### 1. 호텔 예약 취소 예측
- **기간**: 2022.05 ~ 2022.06 (개인)
- **데이터**: Kaggle 호텔 예약 데이터 (2015.07 ~ 2017.08, 시티호텔·리조트호텔 2종)
- **분석**: Random Forest / KNN / 로지스틱 회귀 3종 모델 비교
- **결과**: Random Forest 정확도 95%로 최고 성능. 리드타임은 취소 여부에 영향 없음을 확인
- **파일**: `hotel.ipynb`

### 2. 흉부 X선 폐렴 진단
- **기간**: 2022.05 ~ 2022.06 (개인)
- **데이터**: Kaggle 흉부 X선 영상 데이터 (Train/Test/Validation)
- **분석**: CNN(합성곱 신경망) 기반 이미지 분류, 데이터 불균형 문제 전처리로 해결
- **결과**: 정확도 91% 달성
- **파일**: `pneumonia-cnn.ipynb`

### 3. 강남대학교 챗봇 구현
- **기간**: 2024.03 ~ 2024.06 (팀 프로젝트, 3인)
- **역할**: 다양한 질문 표현에 맞춘 intent 분류 설계, entity 인식 오류 수정
- **데이터**: 학교 홈페이지 Q&A·공지사항·분실물 정보 스크래핑
- **사용 기술**: Dialogflow (Intent/Entity 설계)
- **파일**: `강남대학교 챗봇구현.pptx`

### 4. 아고다(Agoda) AI 서비스 개선
- **기간**: 2024.11 ~ 2024.12 (개인)
- **내용**: 사용자 경험 분석 기반 서비스 개선안 도출, 디자인씽킹 프로세스(공감-정의-아이디어화-프로토타입-테스트) 적용
- **개선안**: 가격 보증 시스템, 여행 목적 기반 추천, 통합 일정 관리, 실시간 대안 제시
- **파일**: `아고다_AI서비스개선.pptx`

### 5. 광주광역시 산불발생 현황 분석
- **기간**: 2023 (팀 프로젝트, 2인)
- **데이터**: 공공데이터포털, 광주광역시 산불발생 현황 (2011~2022)
- **분석**: 결측치 처리, 단위 변환, 파생 변수 생성(총동원인력·총동원기계), 상관관계 히트맵, 산점도 분석
- **인사이트**: 소요시간과 피해면적 간 강한 양의 상관관계(0.49) 확인
- **파일**: `WildFire.ipynb`

## 기술 스택

`Python` `R` `Pandas` `Scikit-learn` `TensorFlow/Keras` `ggplot2` `Dialogflow` `Plotly` `Seaborn`
